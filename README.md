Surge-rider: a momentum breakout bot that trades paper SOL on a replay of pump.fun bonding-curve events. It buys only when several different wallets are pushing SOL into a curve, the flow is accelerating, and the price is pressing its window high — then pyramids into strength and exits on a stop, a trailing stop, a fade in flow, or a time limit. See STRATEGY.md for the full rules.

Paper money only: the bot runs on the replay's paper SOL and never touches real money, real wallets, or any network.

## Run it

```sh
node main.ts
```

The grader runs `node main.ts` against the replay harness (agent-fun/replay/v2, Node 22.18+). No dependencies to install.
